# 🌐 Персональный сайт-визитка

[English version (README.md)](./README.md)

Персональный сайт-био со ссылками на профили и контакты. Я часто использую эту площадку для экспериментов с новыми фичами, дизайном и веб-технологиями.

🔗 **Демо:** [artho-bio.vercel.app](https://artho-bio.vercel.app)

---

## ✨ Особенности

- 🧪 **Площадка для экспериментов:** Сайт регулярно обновляется, проверяются новые идеи и интерфейсные решения.
- 📬 **Обратная связь:** Удобные способы связаться со мной напрямую.
- 📱 **Адаптивность:** Полная поддержка мобильных устройств и ПК.
- ⚡ **Скорость работы:** Быстрый отклики и хостинг на Vercel.

---

## 🛠️ Стек технологий

- **Frontend:** HTML5, CSS3, JavaScript
- **Хостинг:** [Vercel](https://vercel.com)
